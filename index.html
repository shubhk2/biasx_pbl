BiasX: Algorithmic Fairness Evaluation & Mitigation System

"A web-based system for detecting, analyzing, and mitigating bias in datasets and machine learning predictions using IBM AIF360 fairness metrics and preprocessing mitigation algorithms."

Problem Statement

Modern data-driven systems often inherit historical bias present in datasets. When deployed in high-impact domains such as hiring, credit approval, or admissions, biased models can produce unfair outcomes for protected groups. There is a need for an integrated, easy-to-use system that bridges fairness theory with practical deployment.

Understanding Bias

Bias in machine learning is often misunderstood as simple imbalance or discrimination. It refers to systematic differences in outcomes across protected groups . A model may achieve high accuracy yet still produce unequal selection or error rates.

• Bias ≠ Class Imbalance

• Multi-Dimensional

• Context-Dependent

Literature & Existing Tools

Studied IBM AIF360, Microsoft Fairlearn, and Google Fairness Indicators. Most solutions require deep ML integration and lack intuitive visualization, mitigation comparison, and educational deployment support.

Innovation in BiasX

BiasX integrates AIF360 fairness metrics with mitigation techniques (Reweighing, Disparate Impact Remover, Optimized Preprocessing) in a deployable web-based system, making bias detection accessible.

Mitigation ≠ Correction

Bias mitigation does not mean bias has been completely eliminated. Mitigation techniques reduce measurable disparities, but they operate within the limits of the available data and underlying societal structures.

• They cannot remove historical inequalities embedded in data.

• Improving one fairness metric may worsen another.

• Fairness improvements may involve trade-offs with accuracy.

Fairness is an ongoing evaluation process — not a one-time technical correction.

System Methodology

Input Layer

CSV datasets with demographic attributes (e.g., gender, race). Supports binary labels. Preprocessing includes AIF360 BinaryLabelDataset conversion and protected attribute mapping.

Architecture

Flask REST API backend with Python, AIF360 library for fairness metrics (Disparate Impact, Statistical Parity, Equal Opportunity), and custom mitigation algorithms. Frontend: Vanilla JavaScript with modular architecture.
